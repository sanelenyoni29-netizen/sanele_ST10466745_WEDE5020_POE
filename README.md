Sunrise Bakery Website

## Project Overview

Sunrise Bakery is a responsive bakery website created to provide customers with information about the bakery, its products, location and contact details. The website also allows customers to view the bakery menu and submit an order enquiry.

The website represents Sunrise Bakery, a family-owned artisan bakery based in Stellenbosch.

## Website Pages

The website consists of six main pages:

Home – Introduces Sunrise Bakery and displays some of the bakery's daily specials.
About – Provides information about the bakery's story and values.
Menu– Displays different bakery products, including breads, pastries, cakes and pies.
Order – Contains a form that customers can use to submit an order enquiry.
Location – Provides the bakery's address, opening hours and contact information.
Contact – Allows customers to send a message to the bakery.

 Responsive Design

The website uses Responsive Web Design techniques to improve its appearance on different screen sizes.

CSS Grid and flexible layouts are used to organise website content. Media queries are also used to adjust the layout for mobile phones, tablets and desktop screens.

 Main Features

The website provides:

* Easy navigation between pages
* Responsive layouts
* Bakery product displays
* Product prices and descriptions
* Order enquiry form
* Contact form
* Bakery location and opening hours
* Social media links
* Mobile-friendly design

## External CSS

All website pages are linked to one external stylesheet:

```html
<link rel="stylesheet" href="css/style.css">
```

Using an external stylesheet helps maintain a consistent design throughout the website and makes the CSS easier to manage.
